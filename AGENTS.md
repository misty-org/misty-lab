# misty-lab

Misty's Lab as a module that plugs back into Misty (see HOST.md). It is parked: Misty doesn't ship it, and nothing
here changes until it goes back in. Misty's own AGENTS.md and `@misty/ui`'s DESIGN.md apply to every file here, and
its folders mirror Misty's, so a file keeps its Misty path. Tutor, the cursor companion, and lessons stayed in Misty.
